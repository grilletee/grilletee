## Featured projects

### CV Analyzer API
API REST que analiza CVs con IA y devuelve feedback estructurado en JSON.
`Python` `FastAPI` `Gemini 2.5 Flash` `Pydantic v2` `pypdf` `pytest` · Desplegado en Render

### TCG Agent
Agente de IA autónomo con tool calling multi-ronda, memoria vectorial privada (RAG) y API REST. Consulta la API oficial de Pokémon TCG, cruza datos con búsquedas web en tiempo real y prioriza datos personales del usuario antes de fuentes externas. Incluye frontend completo y resiliencia ante fallos con retry y backoff exponencial.
`Python` `FastAPI` `Gemini 2.5 Flash` `ChromaDB` `Sentence Transformers` `DuckDuckGo Search`

### CRM Empresarial Full Stack

`Java` `Spring Boot` `Angular` `MySQL`
